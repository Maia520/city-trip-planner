# 输出规范、能力边界与免责

## 1. 输出结构

一个合格的输出至少包含：

1. **一句话定位**：谁去、去哪、走哪一档；
2. **同行人摘要**：人数、年龄结构、最弱成员、硬约束、有效步行上限；
3. **ABC 对比表**：同一组硬指标，三档可直接比较；
4. **每档时间轴**：到达/离开、点位、交通、距离、耗时、置信度；多代同游会单列"午休/落座休息"段；
5. **四个数字**：总步行、爬升/台阶、缓冲时长、最晚返程；
6. **每档一句"用 X 换 Y"**；
7. **排除清单**：哪些点位没排、为什么（硬约束、档位裁剪、类型过滤）；
8. **B 计划**：雨天版、夜间版、体力降级版；
9. **风险与免责**；
10. **出行前二次确认清单**。

模板见 `assets/route-output-template.md`。

## 2. ABC 对比表

必须给同一组指标，否则用户感知不到差异：

| 指标 | A 尽兴版 | B 舒适版（推荐） | C 省心版 |
|------|----------|------------------|----------|
| 核心点位 | 5–7 | 3–4 | 2–3 |
| 全天步行 | 8–12 km | 5–7 km | 3–5 km |
| 累计爬升 | 200–400 m | ≤150 m | ≤50 m |
| 室内占比 | 20%–30% | 30%–40% | ≥50% |
| 排队暴露 | 高 | 中 | 低 |
| 预约难度 | 高 | 中 | 低 |
| 撤退难度 | 高 | 中 | 低 |

脚本输出 `comparison.rows` 已含点位数、步行、缓冲、总时长、室内占比、是否在时间窗内、最晚返程；Agent 补充预算、预约难度、在途时长。

## 3. 四个数字为什么必须给

| 数字 | 回答的问题 |
|------|-----------|
| 总步行距离 | 今天到底要走多远 |
| 爬升 / 台阶 | 长辈、婴儿车能不能走 |
| 缓冲时长 | 有没有留出排队、找路、休息的余量 |
| 最晚返程时间 | 会不会误了末班车/回程 |

缺任何一个，都不算完整方案。

> 缓冲时长是"预留余量"，不占用具体点位时间，因此 `projected_end` 可能晚于时间轴最后一段；这是保守估计，不是漏排。多代同游的 90 分钟午休则会单列成 `rest` 段，既计入总时长，也出现在时间轴。

## 4. 排除理由是一等输出

不只说"排了什么"，还要说"为什么没排"：

- 硬约束命中：无直梯、含 120 级台阶、排队 40 分钟超限、医疗不可达；
- 档位裁剪：C 档只保留 2–3 个核心点；
- 类型过滤：B 档不排 optional 点位；
- 数据存疑：评价分布异常，暂不进主路线。

用户对"被排除且告知原因"的接受度，远高于"排了但到现场发现推不进去"。

## 5. 能力边界（明确不做）

- 不做实时排队与实时路况的强承诺；只给风险等级。
- 不做订座、订票、代预约；可给"最晚决策时间"与入口指引。
- 不替代导航；只输出路线骨架，落地导航交给地图 App。
- 不做跨境/多城长线行程；首版聚焦城市内半日到多日。
- 不对"安全"作绝对承诺；夜间路线只做规避建议。
- 不做医疗或无障碍的法定适配认证；只做"台阶/坡道/电梯/母婴室"的事实标注。
- 行程不替代监护；儿童、老人、认知障碍者的走失、跌倒、突发疾病由监护人负责。

## 6. 风险与免责

| 风险 | 表现 | 缓解 |
|------|------|------|
| 数据时效 | 店已倒闭、街区已改造 | 置信度分级 + 最后核实时间 + 二次确认清单 |
| 强度误判 | 把成年人强度套给老人幼儿 | 最弱成员 × 经验系数 + 分档系数 + 硬约束 |
| 刷评污染 | 高分低质、排队陷阱 | 评价分布异常检测；用业态混合度/本地信号替代纯评分 |
| 算法幻觉 | 编造不存在的店或营业时间 | 只输出有来源的 POI；无来源标注"未核验" |
| "最优"≠"合意" | 用户想去的店被剔除 | 必去清单硬保留；提供手动重排入口 |
| 偏好主观 | "烟火气"判定争议 | 展示打分维度，允许用户调权重 |
| 医疗风险 | 高原、海边、山区、夜间 | 只给风险提示与就医路径，不给医学结论 |
| 合规 | 抓取点评/地图数据 | 优先官方 API；评价只做聚合统计；遵守平台条款 |

免责声明建议原文：

> 本方案基于公开数据与通用体力估算生成，营业时间、票价、预约规则、无障碍设施可能变化，请出行前二次核实。方案不替代监护人责任，也不构成医疗建议。

## 7. 验收指标（产品侧）

- **回头路率**：路线总路程 / 最优路径长度，目标 ≤1.15；
- **时间偏差**：预测到达与实际到达的中位误差 ≤15 分钟；
- **点位存活率**：出行当天 POI 仍在营业比例 ≥95%；
- **硬约束命中率**：方案中仍含违反硬约束点位的比例，目标 0；
- **方案采纳率**：直接使用或微调后使用的比例；
- **投诉率**：以"名不副实/已倒闭/走得太累/老人孩子受不了"为主因的负反馈占比。

## 8. 一句话标准

> 这个 Skill 的价值不在"能推荐多少店"，而在"能把约束排成三档走得完、且敢标注不确定性的线"。
