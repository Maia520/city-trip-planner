# 分年龄群体出行画像与活动适配

> 年龄分段的用途不是贴标签，而是**翻译成四个可计算参数**：体力预算、注意力半衰期、硬约束、决策权重。
> 本文件的数值为可执行的经验默认值（C 级），上线前应通过访谈或小样本校准。

### 分段依据

- 亲子游四阶段（0—2 依赖期、3—6 体验期、6—9 成长期、10—14 独立期）与 12 岁"娱乐导向转人文研学"的分水岭，是本表 A1—A4 的主要依据。
- 50—59 岁是银发出游主力（约占银发群体 75%）；65 岁后转向便利与保健，70 岁后转向医疗与低强度，属行业普遍观察。
- 研学类活动一般安排在小学四到六年级、初中一到二年级、高中一到二年级。

## 2. 组合人群：最弱成员定上限

### 核心规则

```text
party_walk_factor = min(各成员 walk_factor) × 经验安全系数
                   （novice 0.85 / experienced 0.92）
party_buffer      = max(各成员 buffer_ratio)
party_queue       = min(各成员 queue_tolerance_min)
hard_constraints  = union(各成员 hard_constraints)
```

**不取平均，取最弱成员的下限再打折。** 三代同游的公开经验是"每天 1—2 个核心点位、步道平缓、有代步工具、午休留足"，而不是成年人的 4—5 个点位。

### 六类组合的冲突与调和

| 组合 | 主要冲突 | 调和方法 |
|---|---|---|
| 多代同游（带娃 + 带老人） | 节奏、体力、兴趣三重冲突 | 代步工具一票否决；每天 1—2 个核心点；12:00—14:30 不排程；设"分头行动 + 汇合点" |
| 亲子家庭 | 父母按成人强度排，孩子第二天罢工 | 以孩子年龄定上限；每天 2—3 个点；"大人尽兴"与"孩子尽兴"各占半天 |
| 情侣 | 一方要出片、一方要躺平 | 一人一个主项目；把拍照点与休息点合并（咖啡馆、观景台） |
| 朋友结伴 | 预算、节奏、口味分歧 | 预算前置；分时段自由活动；餐饮选"可共享 + 可单点" |
| 独自出行 | 夜间安全、无人照应 | 行程可中断；住交通枢纽附近；紧急联系人卡片 |
| 团建/同学聚会 | 强制参与、破冰尴尬 | "核心环节 + 自由选择"两段式；按体力分 A/B 线 |

### 多代同游专项校准（70+ 与 4-6 同时在场）

"经常带 70 岁父母 + 5 岁孩子"是一类高频、可复用的组合，默认参数单独收紧：

| 项目 | 校准值 | 理由 |
|---|---|---|
| 组合强度 | min(70+ 0.40, 4-6 0.50, 成人) × 0.92 | 熟悉照护节奏，但安全系数仍不打满 |
| 有效步行上限 | 基准 6 km → 约 2.2 km（B 档） | 70+ 全天 1.5–3 km 取中值 |
| 点位上限 | A 4 / B 3 / C 2 | 多代同游每天 1–2 个核心点 + 1 个缓冲点 |
| 缓冲下限 | 30% | 午休、如厕、情绪安抚 |
| 午休保护区 | 12:00–14:30，90 分钟 | 刚性约束，写入时间轴 |
| 打车阈值 | 超过 1.2 km 即打车 | 避免 70+ 与 5 岁长距离步行 |
| A 档强度 | 最多上浮 10%，并标"不建议全员" | 需要时拆成成人线 + 老人孩子线 |

如果用户标注 `experience_level=experienced`，安全系数从 0.85 提到 0.92，但不会取消午休、台阶、室内备选等硬约束。

### 冲突前置暴露

方案里直接写清："老人 14:00 自行返回酒店，孩子 13:00 午睡，二者不可合并。" 用户对"提前告知的妥协"容忍度，远高于"到现场才发现"。

### 矩阵用法

1. **先做排除，再做推荐**。把 0 分活动直接移出主方案，并在"为什么没排"里说明。
2. **组合判断，不单点相加**。"上午博物馆 + 下午主题乐园"对 7—12 岁是高分，对 4—6 岁是灾难。
3. **同一活动换玩法版本**：博物馆对幼儿是"找动物"、对小学生是"任务单"、对老人是"听讲解"、对青年是"出片"。
4. **高强度活动必须标注强度**：登山、主题乐园刺激项目、长距离徒步，对 61+ 与 0—6 岁应给出替代段或分线方案。

## 4. 硬约束清单

硬约束是**一票否决**，不是扣分项。命中即移出主方案，并说明原因。

| 约束 | 触发人群 | 方案动作 |
|---|---|---|
| 婴儿车通行 | 0—3、部分 4—6 | 无台阶、有直梯、轿厢可进推车；核验"电梯到不到目标楼层" |
| 母婴室 | 0—3、4—6 | 每 2 小时可达；商场作为确定性补给点 |
| 无障碍/电梯/坡道 | 70+、轮椅 | 全程可无台阶通行；核验电梯是否需工作人员钥匙 |
| 卫生间密度 | 0—6、61+ | 每 45—90 分钟一处 |
| 医疗可达 | 70+、慢病人群 | 30 分钟车程内有医院/医务室，标注急救电话 |
| 餐饮忌口 | 0—3、61+ | 辅食热水、低盐软食、儿童餐、过敏原 |
| 避免台阶/爬升 | 61—70、70+ | 台阶数 > 0 或爬升超限的点位移出或只走外围 |
| 午休刚性 | 0—6、70+ | 12:00—14:30 设为不可排程保护区 |
| 排队上限 | 0—6、61+、70+ | 超过容忍度的点位标记风险或替换 |
| 夜间限制 | 0—6、70+ | 21:00—22:00 前返回，不安排背街 |

## 5. 常见误区

1. **把成年人强度套给老人**：按 61—70 岁 3—5 km 上限排，每 40—60 分钟落座。
2. **给幼儿排长队**：4—6 岁排队上限 10—15 分钟，超时即启动备选。
3. **给青少年只排拍照点**：拍照必须依附"值得看/值得玩"的场景。
4. **忽略多代同游午休**：12:00—14:30 不排程。
5. **把"距离近"当"不累"**：200 级台阶 + 石板路可能等于 6 km 平路，台阶数要单列。
6. **用"适合亲子"覆盖所有年龄**：4—6 岁与 7—12 岁结构完全不同。
7. **低估交通与排队的隐形体力**：在途与累计站立等待要单列。
8. **把网红店当必去**：设排队上限，超时启动备选；老人幼儿直接排除。
9. **忽略回程体力**：末日只排酒店周边轻量点位，预留 3 小时到交通枢纽。
10. **把"有电梯"当"无障碍"**：核验电梯位置、楼层、是否需要钥匙。
